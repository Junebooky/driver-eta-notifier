## 기사 화면

기사 운행보고를 입력 폼 대신 **VIP리무진코리아와의 대화방**으로 제출합니다. 한국 시간 오늘 날짜, 좌우 말풍선, 고정 입력창, 전송/재전송, 보고 양식, 영속 이전 대화를 제공합니다. 기존 운행일지 기능은 유지하고 별도 채팅방 링크를 연결했습니다.

## 서버/HQ

원문·기사 UUID·대화/자동 응답을 먼저 저장하고 PR #45의 OOXML writer로 회사 Excel에 자동 누적합니다. 전체 번호판/유일한 끝 네 자리와 차량 마스터 UUID를 매핑하고, 전체 경유지·반복 장소·원문 순서를 유지합니다. 일반 OT와 심야가 겹치지 않도록 I열만 채우며 J~L 청구액은 추정하지 않습니다.

HQ 원본 등록/불변 백업·버전·복구·기사별 제출·확인/수정 이력·재처리·최신 다운로드를 추가했습니다. CAS와 PostgreSQL 조직 잠금으로 동시 쓰기를 직렬화하고, 제출/Excel 상태를 분리해 파일 실패 시 원문과 마지막 성공 파일을 보존합니다. 복구 manifest는 누락 제출을 다시 대기 상태로 돌립니다.

- HQ 실컴포넌트: 차량 확인 수정→승인→Excel 반영→회사 응답/감사 이력 보존

## 운영 전

마이그레이션은 **초안이며 운영 DB에 적용하지 않았습니다**. 회사가 승인한 월별 시트가 들어 있는 파일을 HQ에서 최초 등록해야 하며, 누락 월 양식은 임의 생성하지 않습니다. 심야는 현재 22:00~다음 날 06:00(사용자 확인 완료), 원본/버전은 DB bytea 저장이므로 보존 용량을 검토해야 합니다. 실제 Safari/Excel 데스크톱 검수와 회사 정책 확인을 거쳐야 합니다.
