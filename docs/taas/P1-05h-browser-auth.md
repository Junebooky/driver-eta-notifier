Parent #154 at 526bdc5. Workflow and combined-status connectors returned no results for #152–154; local repository clone also failed DNS resolution. Six new mock test cases are added, not executed here. No CI or browser pass is claimed.

Candidate browser adapter uses only the fixed relative /api/tenant/auth/session, same-origin cookies, no-store and redirect rejection. No tokens or account identifiers in cross-tab messages. Login/logout serialize with the existing origin lock; re-read before mutation, refuse login over an existing/refresh-needed session, refuse stale logout when identity differs, and invalidate local/other-tab cache leases around mutations. Explicit reconciliation after login; no automatic retry for ambiguous failure. Unsupported Web Locks or BroadcastChannel fails closed. These conservative browser compatibility and full invalidation defaults are engineering choices, not server authorization.

Logout with expired access requires explicit reconciliation first; server-side identity-bound mutation and concurrent revocation, refresh ambiguity and cross-tab reconciliation remain release gates.
