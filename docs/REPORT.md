## 2. 세부 구현 내역

### 1) 모바일 Safe Area Inset 완벽 방어 (`components/Header.tsx`)
- **문제 해결**: 거치대에 스마트폰을 장착하고 운행 시 상단 다이내믹 아일랜드나 노치, 시스템 시간/배터리 영역이 헤더와 겹쳐 조작 실수 및 시인성 저하를 유발하던 문제 해결.
- **적용 규격**: `pt-[max(env(safe-area-inset-top),1.25rem)] pb-2.5 px-4`
- **효과**: `viewport-fit=cover` 환경에서도 최소 20px 이상의 안전 여백이 상단에 확보되어, 어떤 스마트폰 기종에서도 시스템 UI와 런처 조작계가 완벽히 분리됨.

### 2) 네브바 군더더기 제거 및 극도의 미니멀화 (`components/Header.tsx`)
- **군더더기 배제**: 드라이버에게 실질적인 필요성이 낮은 대형 영문 로고 타이틀('PROTOCOL COCKPIT')과 방패(Shield) 그래픽을 과감히 제거.
- **필수 정보 집중**: `[4호차 • 윤태준 기사]`와 같은 핵심 식별자만 콤팩트한 슬레이트 알약형 태그로 좌측에 두고, 우측에 40~44px 원형 내비게이션 체인저 3종과 프로필 설정 버튼만 직관적으로 배치.

### 3) 티맵(TMAP) 퀵 체인저 공식 신규 BI 리뉴얼 (`components/Header.tsx`)
- **디자인 표준화**:
  - 기존의 단색 붉은 원형 심볼에서, SK TMAP의 공식 최신 BI 가이드라인에 부합하는 곡선형 그래디언트 'T' 로고로 전면 개편.
  - 배경: 깨끗한 순백색 원형 바탕 (`bg-white border border-slate-200 shadow-xs`).
  - 로고: `#E11D48`(로즈/마젠타) → `#9333EA`(퍼플) → `#06B6D4`(시안/블루)로 이어지는 정밀 인라인 SVG 그래디언트 렌더링.
  - 40~44px 원형 규격 및 액티브 링(`ring-2 ring-offset-2 ring-blue-600 scale-105`) 일체화.

### 4) 출발지 / 목적지 개별 선택 & 양방향 맞교환(Swap) UX (`components/OriginDestinationSelector.tsx`, `app/page.tsx`)
- **양방향 인터랙션 구조**:
  - 최상단에 [출발지] 카드와 [목적지] 카드를 독립된 모듈로 배치.
  - 현재 입력 타깃 상태(`selectionTarget: 'origin' | 'destination'`)를 제공하여, [출발지] 카드를 탭하면 블루 링(`ring-2 ring-blue-500`), [목적지] 카드를 탭하면 에메랄드 링(`ring-2 ring-emerald-500`)으로 하이라이트 전환.
  - 아래 거점 칩을 누르면 현재 선택된 타깃에 해당 명칭·주소·좌표가 즉시 매핑.
- **원터치 맞교환 (⇄)**:
  - 두 카드 사이에 양방향 화살표(`ArrowLeftRight`) 버튼 배치.
  - 터치 즉시 햅틱 펄스와 함께 출발지와 목적지 좌표/명칭이 맞바뀌며, Next.js 라우트 계산 훅이 즉시 트리거되어 반대 방향의 실시간 ETA 및 거리를 즉각 산출.

### 5) 거점 목록 간소화 및 3열 고밀도 배치 (`components/PresetButtons.tsx`)
- **불필요한 장식 제거**: 섹션 타이틀('VIP 거점 원터치 선택')과 비행기, 호텔, 깃발 등의 장식용 이모지 아이콘을 전면 삭제.
- **3열 고밀도 그리드 (`grid grid-cols-3 gap-1.5`)**:
  - 모바일 세로 화면에서 한 화면에 모든 거점이 한눈에 들어오도록 텍스트 중심의 콤팩트 칩으로 재설계.
  - 현재 지정된 목적지는 에메랄드 뱃지, 출발지는 블루 뱃지로 칩 내부에 깔끔히 표시.
  - `[+ 추가]` 버튼을 3열 그리드의 마지막 칩으로 자연스럽게 결합하여 세로 스크롤을 완전히 제거.

### 6) 토스트 팝업 뷰포트 완벽 가둠 (`components/Toast.tsx`)
- **안전 마진 강제**: `fixed bottom-6 left-4 right-4 mx-auto max-w-sm z-50`
- **화면 밖 밀림 방지**: 좌우 16px 마진 안에서 최대 너비 384px(max-w-sm)로 자동 중앙 정렬되어, 기기 해상도나 거점 명칭 길이에 관계없이 팝업이 화면 밖으로 삐져나가는 현상 원천 차단.
- **단어 단위 개행**: `break-keep` 및 유연한 플렉스 패딩으로 가독성 보장.

### 7) 거점 등록 모달 정돈 (`components/CustomPresetModal.tsx`)
- **불필요한 안내 제거**: TMAP 검색 결과 터치 시 노출되던 기술적 위경도 안내 배너를 제거하여 화면을 한층 정돈.
- **라벨 간소화**: 하단 제출 버튼의 문구를 '커스텀 거점 저장'에서 직관적인 **'저장'**으로 변경.

### 8) 프로덕션 빌드 무결성 확인 및 Git 자동 배포
- **빌드 검증**: `npm run build` 결과 TypeScript 컴파일 0 에러 (813ms), 7개 정적/동적 라우트 정상 번들링 완료.
- **Git 원격 푸시**: `Junebooky/driver-eta-notifier` (`main` 브랜치)에 커밋 및 푸시 완료 → Vercel 자동 배포 파이프라인 트리거.

## 3. 실기기 현장 테스트 가이드 (On-device Field Test Guide)

1. **상태바 Safe Area 및 네브바 미니멀 점검**:
   - 스마트폰에서 `https://driver-eta-notifier.vercel.app` 접속.
   - 상단 다이내믹 아일랜드/노치 아래로 헤더가 여유롭게 위치하여 시간이나 배터리 아이콘과 겹치지 않는지 확인.
   - 좌측 로고가 제거되고 호차 태그와 우측 40~44px 원형 내비 아이콘만 정갈하게 배치되었는지 확인.
2. **티맵(TMAP) 신규 BI 아이콘 확인**:
   - 상단 첫 번째 내비 버튼의 화이트 원형 배경 위 마젠타-시안 곡선형 'T' 로고 시인성 확인.
3. **출발지 / 목적지 개별 지정 및 맞교환(⇄) 테스트**:
   - [출발지] 카드를 탭하여 블루 링 활성화 확인 → 아래 거점(예: [조선팰리스]) 탭 시 출발지로 즉시 지정되는지 확인.
   - [목적지] 카드를 탭하여 에메랄드 링 활성화 확인 → 아래 거점(예: [인천공항 T1]) 탭 시 목적지로 즉시 지정되는지 확인.
   - 중앙의 **[⇄]** 버튼 터치 시 출발지와 목적지가 뒤바뀌며 즉시 실시간 경로가 재계산되는지 확인.
4. **3열 고밀도 거점 그리드 점검**:
   - 거점 목록이 이모지 없이 3열 텍스트 칩으로 한눈에 들어오는지, 스크롤 없이 마지막 [+ 추가] 버튼까지 터치 가능한지 확인.
5. **토스트 팝업 뷰포트 점검**:
   - 거점을 빠르게 탭했을 때 하단 안내 팝업이 화면 좌우 밖으로 잘리지 않고 화면 하단 중앙에 예쁘게 안착하는지 확인.
