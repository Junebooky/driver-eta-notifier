   - `KE012 (입국)`: 대한항공 / 로스앤젤레스(LAX) ➔ ICN / `05:15 (지연 시간 +35분)` / `제2여객터미널 B출구 (수하물 13번)` / T2 1층 입국장 좌표 자동 매핑.
