## 2. 세부 구현 내역 및 컴포넌트 아키텍처

### 1) 출발지 / 목적지 선택 카드 (`components/OriginDestinationSelector.tsx`)
- **순백 카드 및 은은한 컬러 링**:
  - 기존 목적지 카드의 녹색 꽉 찬 배경(`bg-emerald-600`)을 전면 제거하고 두 카드 모두 순백색(`bg-white`) 배경을 채택.
  - 선택된 대상에 따라 출발지는 `border-blue-400 ring-2 ring-blue-100`, 목적지는 `border-emerald-400 ring-2 ring-emerald-100`으로 부드럽게 감싸는 소프트 포커스 링 적용.
- **체크 표시 배지 제거**:
  - 카드 우측 상단의 V자 원형 배지를 삭제하여 시각적 잡음을 줄이고 카드 텍스트와 레이아웃 본연의 가독성 극대화.
- **하단 가이드 바**:
  - 좌측에 블루 원형 'i' 인디케이터(`w-3.5 h-3.5 bg-blue-600 text-white rounded-full`)와 함께 `아래 거점을 탭하면 현재 [목적지]로 지정됩니다.` 가이드 제공.
  - 우측에 `⇄ 맞교환 가능` 텍스트를 배치하여 레퍼런스 시안의 디테일을 정밀 재현.

### 2) 자주 가는 목적지 칩 그리드 (`components/PresetButtons.tsx`)
- **섹션 헤더 통합**:
  - 좌측: 블루 핀 아이콘(`MapPin`) + `자주 가는 목적지` 볼드 타이틀.
  - 우측: `거점 관리` 버튼(`SlidersHorizontal`)을 상단 헤더 우측으로 재배치하여 하단 여백 절약 및 직관성 향상.
- **미니멀 텍스트 칩 디자인**:
  - 비행기, 호텔, 서킷 등 불필요한 이모지를 완전히 제거하고 순수 장소 텍스트 중심으로 단정하게 구성.
  - 선택 상태 표시:
    * 도착지 선택 칩: 순백 배경 + `border-emerald-300 ring-2 ring-emerald-50` + 하단 `• 도착지` 녹색 닷 라벨.
    * 출발지 선택 칩: 순백 배경 + `border-blue-300 ring-2 ring-blue-50` + 하단 `• 출발지` 파란 닷 라벨.
    * 미선택 칩: 부드러운 `bg-slate-50/70 border-slate-200/80` 상태 유지.
- **+ 추가 버튼**:
  - 점선 테두리(`border border-dashed border-slate-300`)와 플러스 아이콘을 적용하여 신규 거점 등록 의도를 명확히 전달.

### 3) ETA 영역 대형 디스플레이 & 고속도로 일러스트 (`components/RouteInfoCard.tsx`)
- **단일 카드 구조화 및 넓은 공간감**:
  - 중첩 카드를 탈피하고 단일 순백 카드(`bg-white border border-slate-100/90 rounded-2xl p-4 shadow-2xs`)로 공간을 넓게 확보.
- **좌표 버튼 제거 및 리프레시 버튼 단독 배치**:
  - 우측에 위치하던 컴파스(좌표) 버튼을 삭제하고, 블루 라운드 스퀘어 리프레시 버튼(`w-11 h-11 bg-blue-600 rounded-xl text-white`)만 남겨 조작 단순화.
- **대형 ETA 타이포그래피**:
  - 도착 예정 시각 **02:52**(`text-3xl font-black text-slate-900`)와 소요 시간 **(51분 소요)**(`text-xl font-bold text-slate-900`)를 한눈에 식별 가능하도록 크기 계층화.
  - 하단에 `이동 거리: 68.8 km (실시간 교통 반영 (TMAP))` 서브타이틀 배치.
- **감각적인 고속도로 & 화이트 세단 SVG 배경**:
  - 카드 우측 배경에 원근감이 느껴지는 곡선 도로면과 아이소메트릭 화이트 세단 차량 일러스트를 인라인 SVG로 렌더링하여 모던 모빌리티 앱의 프리미엄 감성 부여.

### 4) 단톡방 보고 템플릿 선택기 (`components/ReportTemplateSelector.tsx`)
- **섹션 아이콘 & 헤더**:
  - 블루 라운드 스퀘어 문서 아이콘(`FileText`)과 함께 `단톡방 보고` 타이틀 배치.
- **출발/도착 토글 버튼**:
  - **출발**: 활성화 시 솔리드 블루(`bg-blue-600 text-white`) 배경에 화이트 서클 플레이(`Play`) 아이콘 장착.
  - **도착**: 비활성화 시 은은한 라이트그레이(`bg-slate-100 text-slate-600`) 배경에 정갈한 스퀘어(`Square`) 아이콘 적용.
- **실시간 보고 미리보기 카드**:
  - 상단에 `보고 텍스트 미리보기` 및 `실시간 갱신됨` 상태 표시.
  - 순백색 박스 내에 `• 출발지:`가 `• 목적지:` 상단에 위치하는 표준 양식 노출:
    ```text
    [4호차 윤태준]
    • 출발지: 조선팰리스 강남
    • 목적지: 인천공항 T1
    • ETA: 02:52
    ```

### 5) 하단 액션 패널 (`components/ActionPanel.tsx`)
- **1초 패스트패스 버튼**:
  - 솔리드 비비드 블루(`bg-blue-600 hover:bg-blue-700`) + 옐로우 번개(`Zap`) + `1초 패스트패스 (보고복사 + 티맵 (TMAP) 실행)` + 화이트 우측 화살표(`ArrowRight`).
- **카카오톡 단톡방 보고 버튼**:
  - 카카오 옐로우(`bg-[#FEE500] hover:bg-[#FDD835]`) + 다크브라운 말풍선(`MessageSquare`) + `카카오톡 단톡방 보고 (텍스트 복사 + 앱 실행)` + 다크브라운 우측 화살표(`ArrowRight`).
- 두 버튼 모두 라운드 코너(`rounded-2xl`), 충분한 터치 높이(`py-4`), 좌우 대칭 인라인 배치로 레퍼런스 시안과 100% 일치.

## 3. 실기기 운행 환경 검증 가이드 (Verification Checklist)

1. **전체 테마 톤 및 카드 외형 확인**:
   - 모바일 브라우저에서 `https://driver-eta-notifier.vercel.app` 접속.
   - 전체 배경이 부드러운 라이트그레이(`#F6F8FB`)이며, 모든 카드가 순백색 바탕에 은은한 섀도우와 둥근 모서리로 최신 앱 느낌을 주는지 확인.
2. **출발지/목적지 카드 확인**:
   - 목적지 카드의 녹색 꽉 찬 배경이 사라지고, 두 카드 모두 화이트 배경에 은은한 블루/그린 링으로 선택 상태를 표시하는지 확인.
   - 하단에 블루 'i' 아이콘과 안내 텍스트가 정상 노출되는지 확인.
3. **자주 가는 목적지 확인**:
   - 상단에 '자주 가는 목적지' 타이틀과 우측 '거점 관리' 버튼이 한 줄에 위치하는지 확인.
   - 칩에서 비행기/호텔 등 이모지가 제거되고 깔끔한 텍스트로 정돈되었는지 확인.
   - 선택된 칩에 `• 도착지` / `• 출발지` 작은 닷 라벨이 부드러운 테두리와 함께 노출되는지 확인.
4. **ETA 카드 및 고속도로 일러스트 확인**:
   - 우측 GPS 버튼이 사라지고 블루 리프레시 버튼만 남았는지 확인.
   - **02:52 (51분 소요)** 형태로 폰트 크기가 시원하게 표시되는지 확인.
   - 카드 우측 배경에 곡선 도로와 화이트 자동차 일러스트가 조화롭게 녹아들어 있는지 확인.
5. **단톡방 보고 및 액션 버튼 확인**:
   - '출발' 버튼이 솔리드 블루로 활성화되어 있고 화이트 플레이 원형 심볼이 선명한지 확인.
   - 미리보기 창에 `• 출발지:`가 상단에 위치하는지 확인.
   - 하단 '1초 패스트패스'와 '카카오톡 단톡방 보고' 버튼 우측에 각각 화살표 아이콘이 정렬되어 있는지 확인.
